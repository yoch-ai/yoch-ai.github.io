# Yoch AI — האתר

אתר תיק העבודות של יוכבד פולונסקי. HTML, CSS ו־JavaScript רגילים, בלי ספריות ובלי שלב בנייה כדי שהאתר יעבוד.
פותחים את `index.html` ורואים את האתר. מעלים את התיקייה ל־GitHub Pages כמו שהיא.

## מה יש בתיקייה

| מה | איפה |
|---|---|
| הדף | `index.html` |
| העיצוב | `assets/css/site.css` |
| ההתנהגות (ניגון, סינון, נגן) | `assets/js/site.js` |
| **רשימת העבודות** | `assets/data/works.json` |
| טלפון, וואטסאפ, מייל, תחומים, מספרים | `assets/data/site.json` |
| הסרטונים הדחוסים והתמונות שלהם | `assets/media/<שם העבודה>/` |
| הכלי שדוחס סרטונים ומעדכן את הדף | `_tools/build.cjs` |

## להוסיף עבודה חדשה

1. שמים את הסרטון הסופי בתיקייה `פרויק AI\סירטונים סופים\`.
2. פותחים את `assets/data/works.json` ומעתיקים רשומה קיימת. משנים בה:
   - `id`: שם קצר באנגלית, בלי רווחים (למשל `pizza`). זה גם שם התיקייה של הקבצים.
   - `title`: הכותרת של הכרטיס.
   - `pitch`: משפט אחד על הסרט.
   - `stat`: מה זה, בכמה מילים (למשל `פרסומת למסעדה`). האורך של הסרט מתווסף לבד.
   - `category`: אחד מהתחומים ב־`site.json`: `realestate`, `fashion`, `food`, `films`. תחום חדש מופיע כלשונית לבד.
   - `source`: הנתיב לסרטון, יחסית לתיקיית האתר (למשל `../סירטונים סופים/פיצה.mp4`).
   - `alt`: תיאור קצר של מה שרואים בתמונה, בשביל מי שלא רואה.
   - `previewStart`: מאיזו שנייה מתחיל קטע התצוגה (8 שניות, בלי קול).
   - `posterTime` (לא חובה): השנייה של תמונת הפתיחה. אם אין, לוקחים את `previewStart`.
   - `featured: true` הופך אותה לעבודה הנבחרת. `hero: true` מכניס אותה לפריימים שבראש הדף (עד 4).
   - `hidden: true` מסתיר עבודה בלי למחוק אותה.
3. מריצים בטרמינל, מתוך תיקיית האתר:

   ```
   node _tools/build.cjs
   ```

   הכלי דוחס רק את מה שחסר: קטע תצוגה בלי קול (‏720px), גרסה מלאה עם קול לנגן, ותמונת פתיחה. אחר כך הוא מעדכן את `index.html`.
4. אם שיניתם את `previewStart` של עבודה קיימת: `node _tools/build.cjs --force <id>`.
5. אם שיניתם רק טקסט: `node _tools/build.cjs --html`.

צריך `ffmpeg` ו־`node` מותקנים. שניהם כבר במחשב.

## מספרים ותמונה

- **מספרי הוכחה:** ב־`site.json` תחת `proof`, למשל
  `[{ "value": 120000, "display": "120K", "label": "צפיות באינסטגרם" }]`.
  כשהרשימה ריקה, הפס לא מופיע. לא כותבים מספר שאי אפשר לעמוד מאחוריו.
- **תמונה לחלק "עליי":** שמים את הקובץ ב־`assets/img/` וכותבים את הנתיב ב־`photo` ב־`site.json`.
- **כתובת האתר:** כשהאתר עולה, כותבים את הכתובת המלאה ב־`url` ב־`site.json` ומריצים `--html`. ככה נכנסים הקישור הקנוני ותמונת השיתוף המלאה.

## לראות את האתר מקומית

פתיחה כפולה של `index.html` עובדת. לבדיקה כמו באינטרנט (כולל דילוג בסרטונים):

```
node _tools/serve.cjs
```

ואז לפתוח `http://localhost:8765/`.
